슈퍼 히어로 작전 한글 패치 0.8v — 전투 이름 수정판 (2026-10-27)

전투 메시지에서 듀오 맥스웰 등 이름 뒤에 @가 붙는 문제를 수정했습니다.
캐릭터·기체 이름 113개 항목을 전수 검사하고 78개 항목의 표시용 저장 길이를 정리했습니다.
저장한 주인공 이름 형식과 실제 이름·띄어쓰기는 유지합니다.
기존 대화창·띄어쓰기 수정 내용도 모두 반영했습니다.
기존 0.8v의 이름·조사·메뉴·엔딩 이미지·캐릭터/기체 표기 수정도 포함합니다.
같은 화자의 본문은 대화창의 남은 공간을 활용하고, 화자가 바뀌면 새 창에서 시작합니다.
전체 번역 대본 1,215개를 검사해 904개 대본을 추가 수정했습니다.
선택지·층 목록·연출 구분과 젯톤·알건 등 기존 지정 용어는 유지합니다.

이 ZIP에는 패치와 적용 도구만 있습니다. 원본 게임 BIN·오디오·CHD는 포함하지 않습니다.
적용 대상: 일본판 Super Hero Sakusen / SLPS-01776, 원본 BIN 트랙 4개.
원본 Track 1 크기: 682,040,016바이트
원본 Track 1 SHA256: 8166ea83da201ceed3fd49bce61774bad4f87ef3b665dc2a26adc51218f94920
기존 한글판이나 CHD에 이 패치를 직접 적용하지 않습니다.

Windows 적용 방법
1. ZIP의 모든 파일을 새 폴더에 풉니다.
2. Apply-Patch.cmd를 실행합니다.
3. 일본판 원본 BIN 트랙 4개가 있는 폴더를 선택합니다.
4. 원본 검사와 적용이 끝나면 패치 폴더 안에 Korean 0.8v 폴더가 생깁니다.
5. 그 안의 Super Hero Sakusen (Korean).cue를 에뮬레이터에서 엽니다.
원본 파일은 변경하지 않습니다. 같은 출력 파일이 이미 있으면 덮어쓰지 않습니다.
파일 이름이 달라도 크기·SHA256이 맞는 원본 트랙을 찾습니다.

기타 패처
Super Hero Sakusen Korean 0.8v Battle Name Update.xdelta를 일본판 원본 Track 1.bin에 적용합니다.
수정 Track 1 SHA256: 533c2e946c08874253cd85e5e9e1cd75cbbb004a98242b2a6ef590a207644eef
Track 2~4 오디오는 원본과 같습니다. 제공 CUE를 사용하려면 오디오 이름을
Super Hero Sakusen (Korean) (Track 2).bin 등으로 맞춰 같은 폴더에 둡니다.

CHD
별도로 받은 CHD는 지원 에뮬레이터에서 그대로 열면 됩니다.
직접 변환할 경우 패치된 BIN/CUE에서 다음과 같이 실행합니다 (chdman은 ZIP에 미포함).
chdman createcd -i "Super Hero Sakusen (Korean).cue" -o "Super Hero Sakusen (Korean).chd"
